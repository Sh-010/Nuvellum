# Secondary Pages System — route and template audit

Baseline: `main` after newsroom stabilization (`3a70e07`).

## Public page families

| Family | Source | Current behavior | Redesign direction |
| --- | --- | --- | --- |
| Homepage | generated by `scripts/render-editorial-home.mjs` | Approved/frozen | **Do not change** in this phase |
| World region desks | `src/pages/world/[region].astro` | 8 static region routes, generic three-card grid | Editorial regional desk: lead package, desk feed, country/territory index, World Explorer bridge |
| Country desks | `src/pages/country/[country].astro` | one route for every World Explorer entity | Country masthead, direct coverage, regional context, restrained geographic index |
| Section pages | `src/pages/section/[section].astro` | dynamic published sections + Screen & Play + Crime | Section front page: lead package, secondary stories, continuing feed |
| Latest | `src/pages/latest.astro` | all stories in equal cards | Dense chronological edition with quiet section filters |
| A–Z headline archive | `src/pages/headlines/[letter].astro` | 26 routes | Large letter archive, alphabetical rail, dense editorial index |
| Author pages | `src/pages/author/[author].astro` | one route per published author/desk | Author/desk profile header + chronological byline feed |
| Article pages | `src/pages/article/[slug].astro` | bespoke reading template | Preserve reading system; align compact masthead/footer and interior tokens in a later sub-pass |
| Institutional | `about`, `standards`, `corrections`, `contact`, `advertise`, `privacy`, `terms` | one-paragraph placeholder-like pages | Quiet magazine/book layout with shared institutional shell |
| Utility/error | `404.astro`, RSS, robots, sitemap, search index | minimal 404; machine routes | Redesign visual 404 only; machine routes remain untouched |
| World Explorer | `world-explorer.astro` | approved immersive globe | **Do not change** |

## System rules

- Keep the approved homepage and World Explorer visually and behaviorally untouched.
- Interior pages should feel like inside pages of the same newspaper, not reduced homepage clones.
- Reuse one compact interior masthead, navigation, footer, reading-mode control and motion language.
- Use the established ivory / wine / black palette and editorial serif hierarchy.
- Prefer dense editorial lists over repeated equal-size card grids.
- Preserve all route URLs, SEO metadata, article filtering and geographic behavior.
- No fabricated popularity, traffic, geographic or editorial metrics.
- Keep day/night reading mode lightweight.
- Keep motion restrained and perceptible; no large parallax or app-like transitions.
- Existing publication and geography contracts are not part of this visual refactor.

## Delivery order

1. Shared interior shell + story primitives.
2. Section, region, country, Latest and A–Z archive families.
3. Author and institutional pages + 404.
4. Article-page consistency pass.
5. Responsive/browser QA and production preview.
