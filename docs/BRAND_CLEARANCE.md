# Preliminary Nuvellum brand clearance — 25 September 2026

This is a preliminary screening, not a legal opinion.

## Trademark screen

A live search of WIPO's Global Brand Database for the exact word mark **NUVELLUM** returned **0 records** using both an exact-match search and a contains-word search at the time checked.

That is encouraging, but it is not a guarantee of worldwide clearance. National trademark databases and common-law / unregistered uses can still matter.

## Existing uses found

- **Nuvellum**, a productivity / focus app by **Ohev Tech GmbH**, is currently listed in Apple's App Store.
- **Nuvellum**, a document-literacy / training business in Fribourg, Switzerland, is currently operating at `nuvellum.pro`.

Neither result found in this screen is an international news publication, but both are real uses of the same word.

## Domains

RDAP checks at the time of review showed:

- `nuvellum.com` — registered (registration record dates back to 2003; current registrar Squarespace Domains LLC).
- `nuvellum.news` — no RDAP record returned (appeared unregistered at check time).
- `nuvellum.media` — no RDAP record returned (appeared unregistered at check time).
- `nuvellum.co` — no RDAP record returned (appeared unregistered at check time).
- `nuvellum.press` — no RDAP record returned (appeared unregistered at check time).

Recommended first-choice domain for the publication: **nuvellum.news**.

Domain availability can change at any moment; register the chosen domain before publicly announcing it.

## Recommendation

The name is usable enough to continue prototyping, but before spending materially on branding or advertising, run a jurisdiction-specific trademark review for the markets where the publication will operate and sell advertising.
