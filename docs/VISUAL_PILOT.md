# Visual Engine pilot set

Five existing Nuvellum stories are used as the first visual QA set. The point is to test whether a selected visual feels editorially relevant and premium without pretending a contextual file photo depicts an event it did not capture.

## Rules demonstrated by the pilot

- Reporting-source metadata remains private to the newsroom; visual licensing metadata is separate.
- A contextual photo must say so. The page must not imply that a generic data-center or road photo depicts the reported event.
- The image itself is never used as evidence for a factual claim.
- CC attribution is rendered quietly in the hero caption, not as a large “Sources” block.
- Remote Commons thumbnails are a pilot delivery mechanism. Before high-scale launch, decide whether to continue remote delivery or ingest/cache approved assets into Nuvellum-controlled storage while preserving license metadata.
- The automated selector should be allowed to return **no acceptable photo**. In that case, the Nuvellum illustration fallback is preferable to a weak or misleading stock image.
